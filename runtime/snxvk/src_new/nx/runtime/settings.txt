# Every setting of ScarletNX: the game's .ini (the runtime's), the launcher's own and the recompiler's. tools/settingsgen
# reads this file and generates settings.h, the struct Settings that holds every value (g_settings, its members the
# settings' names in snake_case), and the tables (nx/runtime/ini.h's IniOpt) that read and write them. The format,
# a line at a time (leading spaces left out, # starts a comment):
#
#   include FILE          a header the generated tables include, for a constant they name (a range's)
#   list NAME id=Label... the instances of an each block: their id in its key, and the label it is shown by (an _ in
#                         a label is a space)
#   table NAME [SCOPE]    the settings below go in the IniOpt table NAME. SCOPE is runtime (the game's, the default),
#                         launcher (the launcher handles them itself), recompile (the recompiler's, which the launcher
#                         and the driver pass on as --key=value) or llvm (recompile, filled with LLVM's passes and the
#                         options its C API sets, after what the table declares)
#   repeat N ... end      the settings between, once for each of N (1 to N in a key's <N>), interleaved: each setting's
#                         member is an array of N
#   setting NAME          a setting, named as the menus show it; its member is NAME in snake_case and must be unique.
#                         In an llvm table, setting @ID gives LLVM's pass (instcombine) or option (LoopVectorization) of
#                         that ID its name, key and help (name NAME, key KEY, help TEXT, label TEXT under it). An ID
#                         LLVM doesn't have is left out, and said. LLVM's own fill the rest: a pass is "LLVM pass <its
#                         name>", key llvm_pass_<name>, int 0 1 default 1; an option "LLVM <its words>", key
#                         llvm_<option> (the ID in snake_case: key KEY where that reads wrong, FastISel's
#                         llvm_fast_i_sel), LLVM's own value (SETTINGS_UNSET) until it is set
#     key KEY             its key in the .ini (<N> in a repeat, <ID> in an each). An LLVM setting's is LLVM's ID's
#     int LO HI           an int, clamped to LO..HI (C expressions)
#     float LO HI         a float, clamped
#     text SIZE           text, up to SIZE - 1 bytes
#     default VALUE       its value until one is read, as the .ini writes it ("" or none for empty text)
#     default-if MACRO V  its default where MACRO is defined (#if defined): up to four, the first that holds
#     once                written to the .ini only once it is set (the default stays its value until then)
#     words W|W...        the menus' words (ini.h): an int's for LO, LO + step..., a text's value=word
#     step N, shift N     the menus' step and shift (ini.h)
#     label TEXT          the menus' name when it is not NAME (the game's menu shows a page's settings by it)
#     startup             read when the game starts only
#     in-game             the game's own (its menu's, or the driver's): the launcher's Settings leave it out
#     recompile           a game's setting the recompile takes too, as -r's --KEY=VALUE and from a played dump's
#                         options: its row also in g_recompile_game_ini, which the driver links (one value, no set)
#     set FUNCTION        called after each read (ini.h's set), declared by settings.h
#     each LIST           one setting for each instance of LIST, in its order: the member an array
#     help TEXT           its help, a line each
#   section NAME: TABLE[/PAGE], ...   [backend] [launcher]
#                         an .ini section (a launcher one: its Settings' group) and its tables, a page's after /.
#                         backend: applied under the controls' lock (backend_ini), not by options.c
#
# The members' C types: int for int, float for float, char[SIZE] for text; an array for repeat and each.
